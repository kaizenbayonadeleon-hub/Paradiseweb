## 🚀 QUICK START — 3 STEPS & YOU'RE LIVE!

### 1️⃣ FILES YOU NEED
Make sure you have **2 files** ready in one folder:
- `index.html` ← Full website code ✅
- `README.md` ← This file 📄

### 2️⃣ CREATE GITHUB REPOSITORY
- Go to **GitHub → New Repository**
- Name: **`paradise-skateshop`**
- Set to **Public** ✅
- Click **Create Repository**

### 3️⃣ UPLOAD & PUBLISH
1. Drag `index.html` + `README.md` into the upload area
2. Click **Commit changes** ✅
3. Go to **Settings → Pages**
   - Source: **Deploy from a branch**
   - Branch: `main` → Folder: `/root` → **Save**
4. ⏳ Wait ~2 minutes → **YOUR WEBSITE IS LIVE!**
   > 🔗 `https://YOUR-USERNAME.github.io/paradise-skateshop/`

## ⚙️ TROUBLESHOOTING

| Issue | Fix |
|---|---|
| ❌ Link not showing up | Wait 2–5 mins → refresh **Settings → Pages** → make sure Branch = `main` + Folder = `/root` |
| ❌ Can't login Admin | Clear browser cache → login again → Admin account stored in browser only |
| ❌ Orders not saving | Make sure browser allows LocalStorage → don't use private/incognito mode |
| ❌ Photos not showing | Replace placeholder links (`PHOTO-XXX`) with valid image URLs (Imgur, Google Drive public link, etc.) |
| ❌ Need to change Admin Password | Create new `index.html` → clear browser data → redo one‑time signup |

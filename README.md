 **Your Local Skate Hub — Built by Skaters, For Skaters**
 📍 Taytay, Rizal, Philippines
 ## 🚀 How to Publish on GitHub Pages
 1. Create a new repo → name it: `paradise-skateshop`
 2. Set visibility to **Public**
 3. Upload these 2 files: `index.html` + `README.md`
 4. Go to → **Settings → Pages**
 5. Source: **Deploy from a branch** → Branch: `main` → Folder: `/root` → Save
 6. Wait ~2 mins → your site goes LIVE at:
    `https://YOUR-USERNAME.github.io/paradise-skateshop/` ✅
 ## 📌 What to Edit Next
 - Replace `YOUR-USERNAME` in index.html → canonical link
 - Swap placeholder icons 🛹 with your real shop photos
 - Update phone/email/prices to your real details
 - Embed your real Google Maps embed code
 - Add more products & photos
